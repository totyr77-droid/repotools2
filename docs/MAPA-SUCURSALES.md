# Mapa de sucursales

Leaflet 1.9.4, distribución local en `js/vendor/leaflet` con licencia BSD, se carga al abrir el mapa. Usa mapas estándar de OpenStreetMap directamente desde el navegador, con atribución visible y caché normal del navegador. No cuenta, clave ni facturación adicional. Servicio público sin SLA: revisar proveedor al crecer el uso. No precarga, descargas masivas ni mapas offline. Política: https://operations.osmfoundation.org/policies/tiles/.

En Usar palet / Cambiar sucursal, Por ubicación solicita posición una vez al abrir el mapa y centra la vista. Mi ubicación permite repetir. Posición del usuario solo en memoria, no se envía a nuestra API ni se guarda en su perfil. Si no hay permiso, error o timeout, se puede recorrer el mapa o usar Buscar. Solo se muestran sucursales registradas con coordenadas; tocar un marcador y Seleccionar sucursal vuelve a Buscar para confirmar Guardar / Usar palet.

Agregar sucursal está siempre disponible, sin icono + y con estilo compacto. Ubicación en el mapa se despliega dentro del formulario: tocar el mapa marca el local, Quitar ubicación deja ambos campos vacíos. Coordenadas opcionales; las sucursales históricas sin coordenadas siguen en la lista. No se geocodifican direcciones ni se importa un directorio externo de comercios. Admin/manager pueden abrir una sucursal asignada y usar Editar datos del local para completar o corregir el punto; los usuarios comunes crean pero no modifican sucursales compartidas existentes.
